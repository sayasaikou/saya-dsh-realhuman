## A · 防静默失效（最急，与分期无关）

这两条不修，坏了不报错，只是机制静静地不干活。**任何新功能之前先做。**

- [ ] **注入加预算压力测试** —— 借 `#70`
  用真实量级的记忆卡（几百条）跑一次注入，断言心情小节仍在；被裁时日志里要有一行。
  现在只测过「记录少时能渲染」。
  验：故意把预算调到 200 字，心情小节被裁时会报一行，而不是默默消失。

- [ ] **注入游标加 bootId 基线** —— 借 `#67`
  插件热重载后 `eventSeq` 从 1 重来，旧的 `since` 会让过滤永远为空。
  验：热重载插件后下一轮，注入里仍带心情；空的时候要能区分「真没有」和「游标卡死」。

## B · v0.1 状态层增补

- [ ] **`why_ref` 加 owner 四分** —— 借 `#60`
  四值：`self` / `owner` / `member` / `media`。现在只要求「指得出事件」，分不出那是他说的还是她自己想到的。
  验：同一条事件写两次心情，owner 不同，观测页上分得开。

- [ ] **观察账本：同一件事出现过几次** —— 借 `#60`
  `domain|对象` 做 key，记次数 / 首末时刻 / 谁提的 / 正反评。
  用得上的地方：同一件事被提三次比提一次重，而这个目前无法表达。

- [ ] **衰减抄节奏、不抄公式** —— 借 `MEMORY_CARD §5`
  只拿三条：「每天最多降一档」「停机后补跑（上限 30 天）」「遗忘 = 删正文只留计数」。
  ⚠️ **不要它的 `targetClarity()`** —— 它按「重要度＋天数」算，那是时间驱动的物理衰减，跟「心情必须有来处」互斥。
  验：停机 N 天再启，降档数 = min(N, 30)。

## C · v0.2 沉默（直接能用）

- [ ] **`rh_control` 加 closeGate 式检查** —— 借 `closeGate`
  有待接的话（对方最后一句是提问/求助且她没接）时，`pause` 被拦，并给出一句理由。
  **这是「不想说」和「在躲」的分界线**，也是这整份清单里最值钱的一条。
  验：造一条未接的提问，pause 被拦；接完再 pause 通过。

- [ ] **沉默拆成四种形态** —— 借 `CONVERSATION_CLOSURE §2`
  现在只有「发」和「不发」。缺：看过了划走 / 潜水 / 这段自然结束（留 summary＋nextOpening）。
  **`close` 不是 `pause`**：前者不改唤醒配置、留结束点；后者是真的进静默。
  验：走完 close 后，他再开口她能正常醒，且知道上次收在哪。

- [ ] **回执四态** —— 借 `#58`
  `sent` / `silent` / `failed` / `interrupted`。现在只有「对方回了」和「没回」。
  另：不能用 `session.prompt` 的返回值当回执，普通 prompt 只返 `{accepted:true}`。

## D · v0.4 自由时间（改法）

- [ ] **tick 重算，不押一次性定时器** —— 借 `#58`
  `nextFireAt` 落盘，每次 tick 重算「现在该不该出发」；重启时在途回合记 `interrupted`，**不补发**。
  现在的随机定时是「排一次、睡到点」，重启/时钟跳变/DSH 掉线都会丢。

- [ ] **「为什么没说话」也落盘** —— 借 `#32`
  只写「做过什么」不够，要写「为什么没做」：判定依据、各项证据数、冷却到什么时候。
  验：页面能看到「上次醒来没说话，因为 X」。

## G · 不抄（写在这防止将来自己忘了为什么）

1. **打分表** —— `score = 需求向量·(0.35+驱动) + …` 九个加权项，最后拿这个分决定叫不叫醒她。
   跟状态层第二稿「不做情绪分/加权求和/心情指数」直接冲突。**是架构互斥，不是程度差异。**
2. **定时驱动当动机** —— 60 秒 tick 是抗重启的手段（见 D），不是目的来源。
3. **14 标签设置页 ＋ 39 工具面** —— 那是「给用户调」的规模，不是「她有状态」的规模。现在四个工具正好。

## 一句话记住

**那条线在 `closeGate` 的注释里：把「不想回」和「逃避」分开，前者可以收尾，后者必须先答。**
我们做「可以不说」的同时，必须同时做这条闸。只做前半，她得到的是赖账的自由，不是选择沉默的自由。
