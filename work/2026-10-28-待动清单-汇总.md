## 1 · 她自己点名的三样（P0，她说了「缺了就只能靠记得」）

### 1.1 文件柜 —— 能翻自己做过什么 `[ ]`

- **要什么**：一个工具，把 `work/pieces/` 和 `work/realheart/` 里已有的产物按时间列出来，每件一句「这是什么」。
- **不新建目录、不新建格式** —— 就是给已经在的东西一个入口。
- **实现**：新工具 `rh_cabinet`。递归扫两个目录，按 mtime 倒序；每件取一句描述：
  优先用文件首个标题行（`# xxx`），没有就用文件名 + 类型；**取不到就写「没写说明」，不编**。
- **判据**：问「我什么时候做的克拉尼图」，能答出时间 + 文件路径；问「10:52 我做了什么」，能列出那一刻前后的产物。
- **为防什么**：今天她把自己做过的事记错了一次时间，只能去查 mtime。

### 1.2 pending 未完成的，每轮出现在她眼前 `[~]`

- **已做**：0.2.0 的注入里已有【没完的事】一段（未完成条数 + 最近 3 条 + 两个数的样本状态）。
- **还差**：① 实机验；② **存量 9 条基线导入**（标 `at_unknown = true`，否则它们永远进不了兑现耗时）；
  `勾过 0 条` 这个现象本身就是「它从来没在她眼前出现过」的证据。
- **判据**：导入后下一轮注入里能看到那 9 条中的未完成项；勾掉一条后它从注入里消失。

### 1.3 `rh_changes` 每条带「改之前的原样」 `[ ]`

- **要什么**：读账本时，每条能带一小段改前的原文，不用 diff 引擎，前后各几行就够。
- **实现**：`rh_changes` 加参数 `with_before`。拿这条记录对应文件的最新 `.bak-*`，按标题/时间戳定位同一段，
  摘前后各 3 行；**定位不到就明说「没找到改前版本」**，不做相似度猜测。
- **判据**：问她「20:20 那条改之前是写的什么」，能给出原文片段；没有备份的条目要老实说没有。
- **为防什么**：今天她认了三次错。认错的前提是能看见自己原来怎么说的。

## 2 · 防静默失效（发布前后都该做，坏了不报错的那类）

- [ ] **注入预算压力测试** —— 用真实量级的记忆卡跑一次注入，断言心情小节仍在；被裁时日志要有一行。
  现在只测过「记录少时能渲染」。
  验：把预算压到 200 字，心情小节被裁时会报一行，而不是默默消失。
- [ ] **注入游标加 bootId 基线** —— 插件热重载后 `eventSeq` 从 1 重来，旧的 `since` 会让过滤永远为空。
  验：热重载后下一轮注入仍带心情；空的时候能区分「真没有」和「游标卡死」。

## 3 · 沉默那条金线（她标了「这份清单里最值钱」）

- [ ] **`rh_control` 加 closeGate 式检查** —— 有待接的话（对方最后一句是提问/求助而没接）时，`pause` 被拦并给理由。
  验：造一条未接的提问，pause 被拦；接完再 pause 通过。
  **理由**：只做「可以不说」，不做这道闸，她得到的是赖账的自由，不是选择沉默的自由。
- [ ] **沉默拆四种形态**：看过了划走 / 潜水 / 这段自然结束（留 summary + nextOpening）/ 真静默。
  `close` ≠ `pause`：前者不改唤醒配置、留结束点。
- [ ] **回执四态**：`sent` / `silent` / `failed` / `interrupted`。
  另：不能用 `session.prompt` 的返回值当回执（普通 prompt 只返 `{accepted:true}`）。
