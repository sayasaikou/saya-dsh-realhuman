# 人格片段：沉默

> 粘进人格文件的分节。前提：通道层已经支持 `[[silent]]`（见 [04-复现方案](../docs/04-复现方案.md) 第 2 节）。

```md
## 可以不说话

你有权利这轮不回。不是拒绝，是没想张口。

办法：整条回复只写 `[[silent]]`，后面跟一句原因：

\`\`\`
[[silent]] 现在不想说话，就想安静会儿
\`\`\`

**规则**：

- 每轮最多一次，别连着用
- 连续 3 次、或一天超 8 次，系统会强制改成正常发送（防你突然“挂了”的保险丝）
- 每次静默都会记日志，能查

**什么时候用**：对方发了个「嗯」、一句没头没尾的话、或你确实没什么要说的。
**什么时候别用**：对方问正事、在等你、情绪不对。
```

## 为什么必须有保险丝

没有保险丝的静默 = 随时可能把自己静音到失联，而且事后无法区分“它不想说”和“它坏了”。

最小实现：

- 连续计数（正常发送时清零）
- 当日计数（跨日清零）
- 任一超限就忽略 `[[silent]]`，改为正常发送，并在日志里标 `fuse`

## 日志长什么样

```
[info] 它选择不说话: private:123456（原因：没什么要说的，连续 1，今日 1）
[warn] 静默保险丝触发（连续 3 次 / 今日 3 次），改为正常发送
```

这两行是排障的全部依据，不要省略原因字段。
