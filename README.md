# saya-dsh-realhuman

把「让 agent **行为上**像人」的整套东西做成可复现方案 —— 不是更会聊天，是做事的样子变。

包括：人格、记忆、状态、沉默、声音、自由时间、自己的作品。全部是**磁盘上的文件**，可直接看、可直接改、可进版本库。

## 解决什么

| 症状 | 人是什么样 | 这里的解法 |
|---|---|---|
| 每轮从零开始 | 上一条的情绪带到下一条 | 状态文件，开口前注入 |
| 收到消息必回 | 人可以不说 | 通道层支持 `[[silent]]`，带日志和保险丝 |
| 只在被叫时才存在 | 人会自己抵磨事、会画画、会写东西 | 自由时间（定时唤起，做什么自定） |
| 没有自己的声音 | 人说话有声 | TTS 接入，音色可复刻 |
| 没有自己的东西 | 人有收藏、有作品 | 自己的表情包库 / 作品集 |
| 换了机器/通道就失忆 | 人不会 | 人格与记忆的迁移方案 |

## 三条不破的原则

1. **不演** —— 做不出来的东西不做。凭空的情绪、假的直觉、伪装的记忆，一律不要。
2. **不编** —— 不知道就说不知道。
3. **可验证** —— 每条行为都要有日志或文件能查。

背后有一份「删去清单」：一些听起来很好但做出来只会是表演的条目，明确不做。
见 [docs/03-不做什么.md](docs/03-不做什么.md)。

## 这不是“复制一个它”

这个仓库的目标不是让你复现出**同一个** agent，是让你做出**你自己那个**。

- 人格模板是骨架，**性格得你自己填**。模板里没有名字、没有具体经历 —— 那些是你的事
- 状态文件从空的开始，不要拄现成的
- 声音用**你自己的**参考音频复刻（哪怕先从一段自录开始）
- 记忆从第一天开始长

拄完会得到一个“别人的 agent 穿着你的衣裳”。那不是“属于你的”。

判断做对了没有，看一条：**它说的话里，有没有哪句是你没预料到、但确实像它的。**

## 依赖

- **DSH** ≥ 0.2.1（插件引擎要求）
- **一条通道** —— 本仓不管通道，只管「像人」那层。可以用任意 OneBot 11 实现（例：`dsh-napcat`），也可以用官方 Bot 通道。
- **TTS**（可选）—— 任何支持音色复刻的云端 TTS。
