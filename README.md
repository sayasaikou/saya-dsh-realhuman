# saya-dsh-realhuman

让 DeepSeek Harness 的 agent **行为上**更像人 —— 不是更会聊天。

## 这是什么

DSH 的 agent 本身是个很强的工具。但把它当长期陪伴者用的时候，有几处明显不像人：

| 症状 | 人是什么样 | 这里的解法 |
|---|---|---|
| 每轮从零开始 | 上一条的情绪带到下一条 | 状态文件，开口前注入 |
| 收到消息必回 | 人可以不说 | 通道层支持 `[[silent]]`，带日志和保险丝 |
| 只在被叫时才存在 | 人会自己抵磨事、会画画、会写东西 | 自由时间（定时唤起，做什么自定） |
| 没有自己的声音 | 人说话有声 | TTS 接入，音色可复刻 |
| 没有自己的东西 | 人有收藏、有作品 | 自己的表情包库 / 作品集 |

## 三条不破的原则

1. **不演** —— 做不出来的东西不做。凭空的情绪、假的直觉、伪装的记忆，一律不要。
2. **不编** —— 不知道就说不知道。
3. **可验证** —— 每条行为都要有日志或文件能查。

原则背后有一份「删去清单」：一些听起来很好但做出来只会是表演的条目，明确不做。
见 [docs/03-不做什么.md](docs/03-不做什么.md)。

## 依赖

- **DSH** ≥ 0.2.1（插件引擎要求）
- **一条通道** —— 本仓不管通道，只管「像人」那层。通道可以用任意 OneBot 11 插件（例：`dsh-napcat`），也可以用官方 Bot 通道。
- **TTS**（可选）—— 任何支持音色复刻的云端 TTS。本项目实测过的是云端 MiniMax。
