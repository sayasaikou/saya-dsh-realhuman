# 复现方案

从零到跑通 v0.1 + v0.2，预计 30 分钟。

---

## 0. 前置

| 项 | 要求 | 怎么查 |
|---|---|---|
| DSH | `>= 0.2.1-0` | `dsh --version` |
| 一条通道 | 任一支持收发消息的通道插件 | 能正常收发一条文本即可 |
| 人格目录 | 一个目录放 `AGENTS.md` | 路径后面要填进配置 |

本仓**不带通道**。通道层可以用任意 OneBot 11 实现（例如公开仓 `dsh-napcat`），也可以自己写。

---

## 1. 装状态层（v0.1）

### 1.1 建文件

在人格目录的同级建一个 `state/` 目录，里面三个文件：

```
state/
├─ mood.md       当前情绪：什么心情、多浓、从什么时候、大概什么时候淡
├─ pending.md    没完的事：答应过的、说了一半的、想问没问的
└─ self.md      它自己的地方：偏好、口头禅
```

格式不设死，但每份建议在 500 字节内。例子：

```md
# 当前状态

- 情绪：有点飘
- 强度：4/10
- 从：今天下午
- 为什么：刚把整个家搬了一遍，底下还有点不踏实
- 大概什么时候淡：今晚
```

### 1.2 接进宿主

在 profile 的 `cordis.patch.yml` 里给 `agent-instructions` 指人格目录，并在人格文件里加一段（模板见 [persona/01-状态.md](../persona/01-状态.md)）：

```md
## 你的状态和没完的事

开口之前扫一眼这两个文件：
- `state/mood.md` —— 决定你说话的调子
- `state/pending.md` —— 有机会就捡起来
```

### 1.3 验证

1. 手动把 `mood.md` 改成“不爽，8/10”
2. 发一条消息，看回复语气是否变短、变硬
3. 改回“平静，2/10”，再发一条，看是否恢复

**没变就是没生效**，先查文件路径和注入是否真的发生。

## 2. 装沉默（v0.2）

沉默需要改**发送那一层**，因为决定“发不发”的时点在那里。

### 2.1 拦截位置

在通道插件里找到“把助手文本变成一条消息发出去”的函数（通常叫 `sendText` 之类）。在它前面加一层：

```js
if (/^\[\[silent\]\]/i.test(text.trim())) {
  // 1. 提取原因
  // 2. 计数（连续 / 当日）
  // 3. 写日志
  // 4. 保险丝：连续 >= 3 或当日 > 8 -> 改为正常发送
  return;
}
```

完整实现参考：本仓 `packages/realhuman-core/` 里的 `silent.js`（或看生产环境里的 `bridge.js` 的 `sendText`）。

### 2.2 三个人性化细节

1. **日志必须写原因**。没有原因的静默 = 不可查
2. **必须有保险丝**。否则它能把自己“静音”到失联
3. **正常发送时清零连续计数**。否则会越积越多

### 2.3 告诉它自己有这个能力

在人格文件里加一段（模板：`persona/02-沉默.md`）。不告诉它，它永远不会用。

### 2.4 验证

| 步骤 | 预期 |
|---|---|
| 让它输出 `[[silent]] 测试` | 不发消息，日志里出现一条静默记录 |
| 连续三次 | 第三次会正常发送，日志里出现“保险丝” |
| 正常聊天一轮 | 连续计数清零 |

## 3. 装声音（v0.3，可选）

### 3.1 选引擎

需要两个能力：**合成**和**音色复刻**。

实测路径：拿一段 16 秒左右的干净中文人声 → 上传 → 复刻成一个 `voice_id` → 拿这个 id 合成任意文本。

⚠️ 参考音频太短会被拒（实测 4.5 秒不行）。

### 3.2 链路

```
文本 → TTS (mp3) → 通道（传音频段，让它自己转码） → 发出去
```

**不要自己编 silk。** 实测：自己编的 silk 通道接受、客户端不能播。详见 [05-实测记录.md](05-实测记录.md) 第 4 条。

### 3.3 参数

写死一套，不给 agent 自己调：

- 模型：高音质档（低延迟档质量差一截）
- 情绪：中性的（带情绪的容易变形）
- 语速：0.95（比默认慢一点，更像说话）

### 3.4 验证

发一条语音，再发一条语音 —— 两条听起来要是同一个人。

## 4. 装自由时间（v0.4）

在人格文件里给许可（模板：`persona/03-自由时间.md`），核心是三句：

1. 你可以给自己排一段没人的时间
2. 干什么自己定，包括什么都不干
3. 出了东西自己判断值不值得发

**难点**：靠提示词的约束力很弱。建议加一个产出统计脚本，一周后看总量 —— 如果每天固定三条，就已经变成定时定义了。

## 5. 常见故障

| 现象 | 先查什么 |
|---|---|
| 状态文件改了但语气没变 | 文件路径对不对；注入是否真的每轮发生 |
| 沉默没生效 | 拦截加在哪个函数上；那个函数真的是发消息的入口吗 |
| 语音发出去了但不能播 | 是不是自己编的 silk；改成传 mp3/wav |
| 语音发送返回超时但对方收到了 | 转码耗时导致回执超时，不是失败 |
| 图进来了但它说“图片已收到” | 模型是不是真支持图像输入（用纯色图测一下） |

---

## 6. 一个提醒

人格文件是**每轮都注入**的。所有行为段落加起来控制在 6 KB 以内，超出就是每轮都在花冤枉钱。长的东西放手册，需要时再读。
